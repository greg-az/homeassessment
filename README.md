# Simple Item Browser — React Take-Home Solution

A minimal, self-contained React + Vite SPA that fetches **posts** from the public JSONPlaceholder API, lets you **search in real time**, and ships with unit tests. 100 % hooks, zero Redux, zero complexity.

---

## 1 Quick Start (5 commands)

```bash
# 1) Clone
git clone <YOUR-FORK-URL> item-browser && cd item-browser

# 2) Install deps (≈ 2 MB)
npm i        # or pnpm i / yarn

# 3) Start dev server
npm run dev  # → http://localhost:5173

# 4) Run tests
npm test     # Vitest + React Testing Library

# 5) Build / Preview production bundle
npm run build && npm run preview
